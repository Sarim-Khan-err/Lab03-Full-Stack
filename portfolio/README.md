Keep style.css and assets/ alongside index.html. Google Fonts are optional; local system fonts are used when offline.

Reference: https://github.com/iluskaland/portfolio-template (author: iluskaland; repository declares MIT licensing).
The reference HTML and CSS were downloaded to reference/ for inspection. The delivered layout and stylesheet are custom, inspired by its portrait introduction, work, skills and contact structure; reference files are not runtime dependencies.
