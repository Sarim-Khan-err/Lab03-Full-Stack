03 / KEEP THESE CLOSE

The field notes.

Short explanations. No rabbit holes.

01 The cascade +

When declarations compete, the browser considers origin and importance, cascade layers, specificity, and then other tie-breakers such as source order. “Last rule wins” only works when the earlier criteria are equal.

Go deeper on MDN ↗
02 The box model +

Every element has content, padding, border and margin. With content-box, width sets the content width. With border-box, width includes padding and border. Margin remains outside both.

Go deeper on MDN ↗
03 Grid vs. Flexbox +

Flexbox lays out a row or column and distributes space along a main axis. Grid gives you rows and columns together. Use the structure your content needs, rather than forcing every layout into one tool.

Explore CSS Grid ↗
04 Semantic HTML +

Choose elements by purpose. Links navigate, buttons act, labels name controls, and headings organize content. Native elements carry behavior that a styled generic container does not.
