# STYLE / SHIFT
Open index.html. A responsive HTML/CSS learning arcade, with no JavaScript or dependencies to install.

- Selector signal: child selectors and specificity.
- Box breaker: content-box and border-box calculations.
- Markup matters: native controls and explicit labels.
- Layout lab: real grid columns, gaps and place-items controls.

Radio buttons, :checked and :has() drive the games. A CSS counter totals the six currently correct answers. Modes retain answers until reset. The arcade reset returns to the first mode and clears all six answers; the lab has an independent reset. No local storage or persistent progress. Optional Google Fonts fall back to installed fonts offline. Current browsers with :has() support are required for interactive feedback; older browsers show all lessons and explanations.

Navigation and inputs support keyboards, visible focus rings and reduced motion. Feedback uses live regions, though announcement behavior with CSS visibility changes can vary by assistive technology. Local asset/anchor and question structure checks completed; browser interaction and visual QA have not been performed.
